Proyecto desarrollado con FastAPI + Docker + PostgreSQL que permite gestionar leyes y documentos jurídicos mediante una API REST

Para ejecutar el Docker Compose:

    docker compose up --build

Para detener el Docker Compose:

    docker compose down 

API:
